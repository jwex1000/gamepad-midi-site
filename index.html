Gamepad MIDI AUv3

Gamepad MIDI turns a game controller into a MIDI controller inside AUM. It is an AUv3 MIDI plugin for iPhone and iPad.

Getting started

  • Connect a game controller that iOS supports.
  • In AUM, add Gamepad MIDI to a MIDI slot.
  • Route its "Gamepad" output to the app you want to play, or to AUM's MIDI Control.
  • Tap the plugin window. It now has the gamepad.

Common questions

The plugin doesn't react to the gamepad.
iOS sends gamepad input only to the window in front. Tap the plugin window to give it the gamepad. Tap another window to give it back.

AUM's MIDI learn doesn't hear the gamepad.
When AUM's learn screen is in front, the plugin can't hear the gamepad. Press the control, then tap SEND in the plugin's strip. Then arm LEARN in AUM. The plugin sends the control's lowest value once a second until you tap the strip again.

Where is my mapping saved?
In the AUM session. Save the session to keep it.
